# Скриншоты проектов

Помещайте полные скриншоты в эту папку с последовательными именами:

- `barber1.png`, `barber2.png`, … — барбершоп;
- `coffee1.png`, `coffee2.png`, … — кофейня;
- `law1.png`, `law2.png`, … — юридический сайт.

Допускаются также форматы `.jpg`, `.jpeg` и `.webp`. Страницы автоматически покажут до восьми экранов и скроют пустые позиции.
